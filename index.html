Soy Luis Alberto Luzon Valencia, conocido como Luis Luva, ingeniero en Electrónica y Telecomunicaciones orientado al Internet de las Cosas, automatización y sistemas embebidos.

Desarrollo soluciones tecnológicas con ESP32, LoRa, sensores, energía solar y diseño PCB, enfocadas en monitoreo, control y automatización de procesos reales. Mi propósito es acercar la tecnología a entornos rurales, agrícolas e industriales mediante proyectos funcionales, escalables y de bajo costo.

Proyectos destacados

Sistemas desarrollados con enfoque en IoT, automatización, energía, agricultura inteligente y control embebido.

Smart Irrigation IoT

Sistema de Riego Inteligente IoT con ThingsBoard

Plataforma de monitoreo y control agrícola basada en ESP32, sensores, electroválvula y medición de caudal. Permite supervisar variables del sistema y controlar el riego desde un panel IoT.

ESP32 ThingsBoard Electroválvula Caudal
Power Monitor Pro

Power Monitor Pro: Control y Monitoreo Solar IoT

Sistema para supervisar voltaje, temperatura, estado de baterías y control del inversor en una instalación solar. Integra visualización web, protección por umbrales y control remoto de cargas.

ESP32 Solar Baterías Inversor
Fuente Variable

Fuente Variable Inteligente con Control PWM

Fuente DC controlada por ESP8266/ESP32 mediante PWM, interfaz web y comandos de voz. Permite seleccionar voltajes rápidos, ajustar la salida y visualizar parámetros como PWM, ADC y pulse width.

ESP8266 ESP32 PWM Web App
Incubadora IoT

Incubadora IoT Pro con Alertas por Telegram

Sistema automatizado para control de temperatura, humedad, ventilación y monitoreo remoto. Integra notificaciones por Telegram para alertas, estados críticos y seguimiento del proceso.

IoT Telegram Sensores Control térmico
Oruga Rover

Oruga Rover: Plataforma Móvil IoT de Exploración

Rover controlado por red local con interfaz web, modo manual y funciones de control para motores, luces, bocina y velocidad. Diseñado como base para exploración, monitoreo y futuras misiones autónomas.

ESP32 Rover Web Control Motores
PCB Control

Módulo PCB de Control con Aislamiento Óptico

Diseño de placa electrónica para control de cargas mediante relés, optoacopladores y separación entre etapa lógica y etapa de potencia. Pensado para sistemas IoT más seguros y ordenados.

PCB KiCad Relés Optoacopladores
